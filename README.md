# Datos de Alicante Tráfico en Vivo

Rama generada por `.github/workflows/data.yml` a partir de los datos oficiales de la
DGT (incidencias, detectores de velocidad y radares) y del histórico de velocidades.
Se reescribe en cada ejecución (un solo commit) para que el repositorio no crezca.
